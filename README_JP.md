# Switch Language (Blender 拡張機能)

2つの表示言語をショートカットキーやUIボタンで瞬時に切り替えることができる、軽量なBlender拡張機能（アドオン）です。また、新規データ（オブジェクト、マテリアル、ワークスペースなど）の名前生成ルールについても詳細に制御できます。

## ✨ 主な機能

* **瞬時の言語切り替え:** 設定画面の奥深くまでアクセスすることなく、設定した2つの言語（例：英語と日本語）をサッと交互に切り替えられます。
* **ショートカットキー:** デフォルトでは `Ctrl + Alt + L` で切り替え可能です（完全にカスタマイズ可能）。
* **トップバーボタン:** 画面右上のトップメニューバーに極小の地球儀アイコン（`🌎`）を追加し、マウスクリックでも簡単に切り替え可能です。
* **名前生成の制御:** 新しく作成するオブジェクト等の名前（Cubeなど）の言語を指定できます。現在のUI言語に関わらず「言語非依存（常に英語）」に固定することもできるため、プロジェクトデータに日本語名などのマルチバイト文字が混入するのを防ぐのに役立ちます。
* **控えめな通知:** 言語を切り替えた際、画面下部のステータスバーに操作を邪魔しない小さな通知を表示します。

## 🖥 必須環境

* **Blender 4.2 以降** （新しい Blender Extensions システムを使用しています）

## 📦 インストール方法

このアドオンは新しいBlender Extensionsとして構築されているため、以下の手順で `.zip` ファイルからインストールしてください。

1. **拡張機能のダウンロード:** このリポジトリからリリースの `.zip` ファイルをダウンロードします。*(※開発者へのメモ: フォルダごとではなく、`__init__.py` と `blender_manifest.toml` を直接選択してZIP化してください)*
2. Blenderを開き、**編集 (Edit) > プリファレンス (Preferences)** を開きます。
3. 左側のタブから **拡張機能を取得 (Get Extensions)** を選択します。
4. 右上の下向き矢印アイコン (⌵) をクリックし、**ディスクからインストール... (Install from Disk...)** を選びます。
5. ダウンロードした `.zip` ファイルを選択してインストールします。
6. リスト内で拡張機能にチェックが入り、有効化されていることを確認してください。

*※注意: 本拡張機能を有効化した瞬間に、Blenderの表示言語は自動的に設定内の「Language 1 (言語 1)」(デフォルトでは英語)に切り替わります。*

## ⚙️ 設定と使い方

インストール後、プリファレンスの拡張機能（またはアドオン）一覧から設定を展開して変更できます。

### 設定項目の概要

* **Language 1 & Language 2:** 切り替えたい2つの言語を選択します（例：英語と日本語）。
* **Name Generation (名前生成):** 
  * `Language 1` / `Language 2`: 新規作成されたデータ（デフォルトのCubeなど）の名前は、選択した言語の翻訳に基づいて生成されます。
  * `Language Independent` (言語非依存): 現在の表示言語が何であっても、新規データ名は**翻訳されません（常に英語になります）**。命名規則を英語で統一しているプロジェクト・パイプライン環境で強く推奨されます。
* **Show Notification (通知の表示):** ステータスバーの通知メッセージのオン/オフを切り替えます。
* **Show Topbar Button (トップバーボタンの表示):** Blender画面右上の地球儀アイコンの表示/非表示を切り替えます。
* **Shortcut Key Setup (ショートカットキー設定):** デフォルトの `Ctrl + Alt + L` から、お好みのショートカットキーに変更できます。
